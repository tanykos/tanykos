**My areas of ownership:**

- **Auth flow:** sign-in/sign-up layouts, validation, Firebase authorization, error handling
- **Protected routes:** in Next.js App Router
- **Resilience layer:** Error Boundary, Not Found page, loading states
- **MUI theme customisation**
- **Unit tests** for AuthForm, FormContainer, Header, PasswordAction

**Stack**: Next.js, React, TypeScript, Firebase Auth, react-hook-form, Yup, MUI, Vitest

🔗 [Code](https://github.com/tanykos/graphiql-app) · [Live demo](https://graphiql-app-azure.vercel.app) · [Video walkthrough](https://youtu.be/iLjk49haH7E)
